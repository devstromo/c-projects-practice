# Session handoff

Copy this template into `.ai/local/` for temporary notes. Use repository-relative
paths and record verified facts. Leave out credentials, private records, and raw
tool logs. This note is context for a future session, not new authorization.

## Objective

Describe the user's requested outcome and any explicit constraints.

## Current state

Record the branch, affected files, completed work, and unrelated local changes
that must be preserved. Separate implemented changes from proposed work.

## Evidence

Record compile/test commands, working directories, inputs, exit statuses, and
outcomes. Note checks not run and why, plus relevant existing warnings.

## Remaining work

List the next concrete steps, unresolved questions, and any reproducible blocker.
Point to the appropriate `.ai/context/` document instead of copying its contents.
